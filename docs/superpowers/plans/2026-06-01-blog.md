# Blog da HB Comércio — Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking. This
> repo has **no test framework** and adding one is out of scope (see spec). In
> place of TDD, each task is verified by running the build and inspecting the
> generated output (`dist/`). Treat the "Verify" steps as the test gate.

**Goal:** Adicionar um blog estático (lista + posts) gerado de Markdown no build, reaproveitando o CSS Tailwind do site, com SEO por post e sitemap atualizado.

**Architecture:** Posts em `content/blog/*.md`. Um script Node (`scripts/build-blog.mjs`) roda depois do `vite build`, converte cada `.md` em HTML via um template (`scripts/blog-template.mjs`) que injeta o mesmo stylesheet hashado que o site gera, escrevendo `dist/blog/<slug>/index.html` e `dist/blog/index.html`, e regenera `dist/sitemap.xml`. Nenhum React/SSR nas páginas de blog.

**Tech Stack:** Node ESM, `gray-matter` (frontmatter), `marked` (markdown→HTML), Tailwind v4 (`@source` para incluir as classes do template), Vite 8.

**Base spec:** `docs/superpowers/specs/2026-06-01-blog-design.md`
**Branch:** `feat/blog`

---

## File Structure

| Arquivo | Responsabilidade |
|---|---|
| `content/blog/*.md` | Fonte dos posts (frontmatter + corpo Markdown) |
| `scripts/blog-template.mjs` | Funções puras que montam o HTML (head, header, footer, lista, post). Contém todas as classes Tailwind do blog (escaneadas via `@source`). |
| `scripts/build-blog.mjs` | Gerador: lê md, renderiza, escreve `dist/blog/...`, regenera sitemap |
| `src/index.css` | `@source` do template + bloco de tipografia `.article` |
| `src/components/sections/Nav.tsx` | Link "Blog" no menu |
| `src/components/sections/Footer.tsx` | Link "Blog" no rodapé |
| `package.json` | Script de build encadeia o gerador + devDeps |

Boundaries: `blog-template.mjs` é apenas apresentação (recebe dados, devolve string HTML, sem I/O). `build-blog.mjs` é apenas orquestração/IO (lê arquivos, chama o template, escreve). Essa separação mantém cada arquivo com uma responsabilidade só e testável por inspeção.

export function formatDate(date) {

Create `scripts/build-blog.mjs`:
```js
// Gera as páginas estáticas do blog em dist/ a partir de content/blog/*.md.
// Roda DEPOIS de `vite build` (precisa do dist/ e do CSS hashado).
import {
  readFileSync,
  writeFileSync,
  readdirSync,
  mkdirSync,
  existsSync,
} from "node:fs";
import { join, dirname } from "node:path";
import { fileURLToPath } from "node:url";
import matter from "gray-matter";
import { marked } from "marked";
import { renderListPage, renderPostPage, SITE_URL } from "./blog-template.mjs";

const ROOT = join(dirname(fileURLToPath(import.meta.url)), "..");
const CONTENT_DIR = join(ROOT, "content", "blog");
const DIST = join(ROOT, "dist");

// 1. Descobrir o CSS hashado que o Vite gerou (lendo o index.html).
const indexHtml = readFileSync(join(DIST, "index.html"), "utf8");
const cssMatch =
  indexHtml.match(/<link[^>]+rel="stylesheet"[^>]+href="([^"]+\.css)"/) ||
  indexHtml.match(/<link[^>]+href="([^"]+\.css)"[^>]*rel="stylesheet"/);
if (!cssMatch) {
  throw new Error("Não encontrei o <link rel=stylesheet> em dist/index.html.");
}
const cssHref = cssMatch[1];

// 2. Ler e parsear os posts (ignorando drafts).
if (!existsSync(CONTENT_DIR)) {
  throw new Error(`Pasta de conteúdo não existe: ${CONTENT_DIR}`);
}
const posts = readdirSync(CONTENT_DIR)
  .filter((f) => f.endsWith(".md"))
  .map((file) => {
    const raw = readFileSync(join(CONTENT_DIR, file), "utf8");
    const { data, content } = matter(raw);
    const slug = file.replace(/\.md$/, "");
    const words = content.trim().split(/\s+/).filter(Boolean).length;
    const readingTime = Math.max(1, Math.round(words / 200));
    const html = marked.parse(content);
    return { slug, data, html, readingTime };
  })
  .filter((p) => p.data.draft !== true)
  .sort((a, b) => new Date(b.data.date) - new Date(a.data.date));

// 3. Escrever a página de cada post.
for (const post of posts) {
  const dir = join(DIST, "blog", post.slug);
  mkdirSync(dir, { recursive: true });
  writeFileSync(join(dir, "index.html"), renderPostPage(post, { cssHref }));
}

// 4. Escrever a listagem.
mkdirSync(join(DIST, "blog"), { recursive: true });
writeFileSync(join(DIST, "blog", "index.html"), renderListPage(posts, { cssHref }));

// 5. Regenerar o sitemap incluindo o blog.
const today = new Date().toISOString().slice(0, 10);
const urls = [
  { loc: `${SITE_URL}/`, lastmod: today, changefreq: "monthly", priority: "1.0" },
  { loc: `${SITE_URL}/blog/`, lastmod: today, changefreq: "weekly", priority: "0.7" },
  ...posts.map((p) => ({
    loc: `${SITE_URL}/blog/${p.slug}/`,
    lastmod: new Date(p.data.date).toISOString().slice(0, 10),
    changefreq: "monthly",
    priority: "0.6",
  })),
];
const sitemap =
  `<?xml version="1.0" encoding="UTF-8"?>\n` +
  `<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">\n` +
  urls
    .map(
      (u) =>
        `  <url>\n    <loc>${u.loc}</loc>\n    <lastmod>${u.lastmod}</lastmod>\n` +
        `    <changefreq>${u.changefreq}</changefreq>\n    <priority>${u.priority}</priority>\n  </url>`,
    )
    .join("\n") +
  `\n</urlset>\n`;
writeFileSync(join(DIST, "sitemap.xml"), sitemap);

console.log(`✓ Blog gerado: ${posts.length} post(s) + lista + sitemap.`);
```
